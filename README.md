# Portafolio Next.js + Tailwind — Adriana

Proyecto mínimo con **Next.js (App Router)** + **Tailwind** y la página del portafolio ya integrada.

## Requisitos
- Node 18+ (recomendado 18 LTS)

## Instalación
```bash
npm install
npm run dev
```

Abre http://localhost:3000

## Dónde poner tu foto y CV
- Foto: `public/avatar.jpg` (ideal 500x500 px, JPG, 200–300 KB)
- CV: `public/cv.pdf`

## Despliegue
- **Vercel**: conecta el repo y despliega (build por defecto).
- **Netlify**: usar adaptador Next.
- **GitHub Pages**: recomendado usar Vercel para Next.js.
